# PAULTJRCO Digital Business Card

A compact, elegant digital business card featuring contact information and the signature "Let's make something..." animation from the Pocket Portfolio.

## Features

- **Landscape business card format** (16:10 aspect ratio)
- **Animated tagline** with rotating words
- **QR code** linking back to this card (self-referential)
- **Responsive design** - adapts to mobile and tablet screens
- **Dark theme** with gold accents matching the Pocket Portfolio
- **Accessible** - proper semantic HTML and ARIA labels
- **Progressive Web App** - works offline with service worker

## Access

Visit: `https://paultjrco.github.io/pocket/card`

## Design Notes

- Uses the same typeface, color scheme, and animation framework as the main Pocket Portfolio
- QR code generates a link to itself (self-referential for digital sharing)
- Optimized for sharing digitally as an alternative to physical business cards
- Can be screenshotted and shared via text, email, or messaging apps
